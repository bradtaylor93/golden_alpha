# RSI(14) band analysis

For each stock/day from 2013 onward, this computes RSI(14) using data through the close, then measures next-close to 14-trading-day-forward return. This is a signal diagnostic, not a turnover/cost-adjusted portfolio backtest.

## Dataset

- Observations: 1,616,415
- Symbols: 504
- Date range: 2013-01-02 to 2026-04-24
- Forward return: next close to +14 trading days
